Универсальная микро-библиотека на чистом JavaScript (ES6+) для управления глобальным состоянием, флагами и объектами модулей "в моменте". Инструмент разработан как полностью автономный, независимый компонент, готовый к переиспользованию в любом веб-проекте без привязки к конкретной платформе или бэкенд-стеку.

## Концепция переиспользуемости
Проект следует принципу модульной автономности. `AppRegistry` работает "из коробки" как изолированный лоскут кода, обеспечивая чистую и независимую связь между другими фронтенд-компонентами на странице без их жесткого взаимного связывания.

## Архитектурный подход
Реестр работает по принципу синхронного запроса данных здесь и сейчас. Модули обращаются к хранилищу напрямую для записи, проверки или получения флагов и инициированных объектов, избегая сложных систем подписок и лишней фоновой логики.

## Структура репозитория
Проект разработан в двух вариантах для демонстрации эволюции кода и преимуществ строгой типизации:

*   `/javascript` — базовая реализация на чистом JavaScript (ES6+).
*   `/typescript` — адаптированная и строго типизированная версия на TypeScript (будет добавлена после завершения JS-версии).

## История версий

### v0.1.0-alpha — 08.09.2026
Минимально жизнеспособный продукт (MVP) для многомерной записи и безопасного чтения данных.

*   **Инфраструктура:** Реализован класс `AppRegistry` с единой точкой входа (**Singleton**) для сквозной коммуникации модулей, а также приватным инкапсулированным хранилищем `#app_registry` для защиты от прямого изменения данных
*   **Метод `set(path, value)`:** Реализована запись состояний с автоматическим построением древовидной структуры объектов и защитой от конфликтов типов промежуточных узлов.
*   **Метод `get(path, default_value)`:** Реализовано безопасное чтение данных из глубины реестра с поддержкой необязательного дефолтного значения.
*   **Парсинг путей:** Внедрен приватный метод `#parsePath(path)`, обеспечивающий поддержку точечной нотации (`'user.name'`) и массивов ключей (`['user', 'name']`) с автоматической фильтрацией пустых элементов.
